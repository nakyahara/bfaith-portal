1名前をえらぶ

なぜ: だれがやったかを記録に残すため。名前は右上でいつでも替えられます。

  1. iPad で作業画面を開くと「この iPad をつかう人をおしてください」と出ます。
  2. じぶんの名前をおします。
  3. 右上に名前が出ます。まちがえたら右上の名前をおして替えます。
作業する人は、はじめるときに別にえらべます (何人でも)。ここでえらぶのは「この iPad をさわっている人」です。

2一覧の見かた

なぜ: 今日やるものと、止まっているものが、すぐ分かるように。

  1. 上のタブ: 📌 今日やる (朝いちばんに見る) / すべて / 未着手 / 作業中 / 棚入待ち / ⛔ 止まっている / 止まっていない
  2. カードをおすと、くわしい画面が開きます。
  • 48 個 = つくる数。📦 2 箱 = 用意する保管箱の数。⏱ 約 12 分 = かかる時間のめやす。
  • 📌 今日やる 今日やる予定。🌱 はじめての商品 この商品ははじめて (前の写真がありません)。
  • ⚠ 未登録 4 資材・保管箱などが登録されていません。カードを開いて「＋ 登録」できます。
  • ⛔ 資材不足で止まっています カード全体が赤いものは止まっています。理由がカードに書いてあります。
  • 右の「未着手 ▾」は状態。おすと状態を変えられます。

3作業をはじめる

なぜ: だれが・どのくらい作業したかが自動で記録され、次回のめやすになります。

  1. カードを開きます。上に「使うもの」(資材・保管箱の写真)、「作業のしかた」(工程・期限シール)、「気をつけること」が出ます。
  2. いちばん下の青い ▶ 作業をはじめる をおします (下に固定されているので、スクロールしなくても押せます)。
  3. 作業する人を全員えらびます (1 人でも 4 人でも)。じぶんは最初からチェックされています。
  4. ▶ N人で作業をはじめる をおすと、タイマーが動きます。
「⚠ 工程が未登録」のカードは、分かるなら先に「＋ 登録」してください (分からなければそのまま始めてもよいです)。

4とちゅうで止める・ぬける

なぜ: 休けいや帰る時間も、時間の記録を正しく残すため。

  1. じぶんだけ先に上がるとき: 「作業する人・時間」の じぶんの名前のよこの ぬける。
  2. みんなで休けい: 下のバーの ⏸ ひとやすみ。もどったら ▶ 作業をはじめる。
  3. 人がふえたら ＋ 人を追加。

5⛔ 止まった (ラベル・資材が足りない)

なぜ: 「なぜ止まっているか」が札で見えると、職員がすぐ手を打てます。カードは赤くなります。

  1. 下のバーの赤い ⛔ 止まった をおします。
  2. 理由を 1 つえらびます: ラベルが足りない / 資材が足りない / 指示待ち / その他。
  3. 資材が足りないのときは、どの資材が何個足りないかをおして (書いて) ください。職員への連絡を自動で試みます (届かないこともあるので、急ぐときは直接声をかけてください)。
  4. 何個までできたか (分かれば) と、次にやる人へのメモを書いて この理由で止める。タイマーは止まります。
  5. 解消したら、いつもどおり ▶ 作業をはじめる。「解消しましたか?」に「はい」で札が外れます。

6できあがり → 棚入待ち

なぜ: 「できあがった」と「棚に入れた」は別の人がやるので、いちど「棚入待ち」でとめます。

  1. 下のバーの ✅ できあがり (みんなで作業していれば「みんなできあがり」)。
  2. 何個できたか (ふつうは全部) を確かめて 棚入待ちにする。
  3. できあがった状態の写真をとる (次に同じ商品を作る人の見本になります。3 枚まで)。
  4. 棚に入れ終わったら、職員が「棚入完了」にします。

7まちがえたとき (もどす)

なぜ: 押しまちがいは起きるもの。直後ならその場でもどせます。

  1. 「ぬける」「ひとやすみ」「⛔ 止まった」をおしたあと、下に黒い帯が出ます。もどす をおすと止めなかったことになります (6 秒間)。
  2. 「できあがり」をまちがえたら、ダイアログの ← まちがえた (まだ作業中)。
  3. 時間がたってしまったら、もう一度 ▶ 作業をはじめる でつづきを始められます。

8さがす・もどる・文字を大きく

  1. さがす: 上の検索らんに商品名・商品コード・JAN (バーコードの数字) を入れます。📷 でカメラから読める iPad もあります (読めない iPad は、検索らんを長押し →「テキストをスキャン」)。
  2. 作業中にもどる: 別の画面を見ていても、上の青い ⏱ 作業中: 商品名 12:34 › をおすと、じぶんの作業にもどれます。
  3. 文字を大きく: 右上の あ⁺。おすごとに 大 → 特大 → ふつう。この iPad におぼえます。
  4. ボード: 未着手・作業中・棚入待ちを横に並べて見る画面。上の「予定」で 今日やる／止まっている などに絞れます。

9きょうのみんなの作業

なぜ: じぶんが今日どれだけやったか、自分で見られるように。

  1. 上の 📚 履歴 → 📅 きょうのみんなの作業。
  2. 人ごとに、商品と時間が出ます。じぶんの分がいちばん上。きのう や日付で前の日も見られます。
ここからは職員の方向けです。

10職員モード

なぜ: 計画・外部出し・終了などは職員だけの操作。PIN で 30 分だけ開きます。

  1. 右上の名前を職員にすると 🔑 職員モードに入る が出ます。おして職員PINを入れます。
  2. 30 分たつか、右上の名前を別の人に替えると終わります (利用者に替えた瞬間に職員の操作は消えます)。
  3. PIN を入れた本人だけの職員モードです。別の職員はその人の PIN で入り直します。
共用 iPad ではポータル (PC 用の管理画面) にログインしないでください。ログインが残っていると、利用者に替えても職員の権限が残ります。

11計画 (どこが・いつ)

なぜ: 「どこが (どの施設が) やるか」「いつやるか」を決めるのは職員の仕事。利用者の画面では決まった予定を見られますが、変えられるのは職員だけです。

  1. ボードのカードの どこが 未定 をおす → いろは／羅針盤／ワークセンター／ジョブサポ／パレット／未定にする。
  2. いつ 未定 をおす → 📌 今日やる／明日やる／未定にする。
  3. ボード上の 📋 明日の計画を立てる で、候補 (在庫が少ない → 入荷が古い → 大きい の順) から「＋ 明日やる」で積みます。1 日のめやすは 4〜6 時間。
  4. カードの中の 📌 今日やる でも今日の予定に入れられます。

12棚入完了・外部出し・ラベル待ち

  1. 棚入完了 (1 枚ずつ): 棚入待ちのカードに出る ✅ 棚入完了 → 確認 → PIN。終了になり一覧から外れます (履歴に残ります)。
  2. まとめて: 棚入待ちの列の まとめて棚入完了 → カードをおして選ぶ → 下の まとめて棚入完了にする → 確認 (一覧が出ます) → PIN。
  3. 外部出し: カードの中の 📦 外部に出す準備OK にする (職員モードのときだけ出ます)。
  4. ラベル待ち: 利用者が「ラベルが足りない」で止めると記録が自動で開きます。発注・本社連絡・入庫完了・完了は職員が 🏷 ラベル待ち タブから記録します。「完了」にすると札が外れます。
  5. 止まっているカード: 資材が届いたら、そのカードで ▶ 作業をはじめる → 「はい、解消した」で札が外れます。作業を始めずに札だけ外すときは、カードの上の赤い枠の 札を外す (職員)。

13管理画面 (PC)

ポータル → いろは在庫化 作業アプリ 管理。よく使うのは上の 3 つ。

  • 👤 名簿: 利用者・職員の追加、職員PIN の設定、並び順。
  • 🧰 選択肢: 資材セット・保管箱の候補と画像 (iPad の「＋ 登録」で選べるもの)。
  • 🔎 記録をさがす: だれが・いつ・どの商品を何分。CSV (管理者のみ)。
  • 📱 iPad: 新しい iPad の登録コード。
  • 🚚 移行: 名前や商品コードの無いカードの片づけ。正本の切替 (もう「アプリ」です)。
  • ⏱ セッション: 開きっぱなしの作業時間の取り消し。

14こまったとき

  • 「サーバーにつながりません」と出る: 前回の一覧を表示しています。少し待つと自動でつなぎ直します。数分たっても直らなければ職員へ。
  • ボタンが出ない: その人にはできない操作です (例: 計画・終了は職員だけ)。名前を替えるか、職員をよんでください。
  • PIN を忘れた: 管理画面の名簿で職員が設定し直します。
  • まちがって止めた (ぬける・ひとやすみ・⛔ 止まった・できあがり): 直後なら「もどす」か「← まちがえた」。時間がたったら、もう一度「▶ 作業をはじめる」でつづきを始められます。
  • まちがって棚入完了 (終了) にした: カードは一覧から外れます。職員に伝えてください (職員がカードの状態を作業中に戻すか、管理画面で記録を取り消します)。
  • カードが見つからない: 一覧のタブが「今日やる」になっていないか確かめ、「すべて」にしてから検索。
