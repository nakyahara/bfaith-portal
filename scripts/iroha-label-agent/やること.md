# 🏷 保管箱のラベルを iPad から出せるようにする — いろはPC でやること

- やる場所 … **いろはPC** (Brother QL-800 がつながっている PC)。このフォルダ (`G:\共有ドライブ\入荷バーコード発行\箱ラベル印刷係\`) にあるものだけを使います
- お金 … **かかりません** (b-PAC は無料。ラベルの枚数も今と同じ)
- やることは **3つ**: ① b-PAC を入れる (10分) → ② テスト印刷 (5分) → ③ 印刷係を住まわせる (5分)

---

## これは何をする作業?

いま、保管箱に貼るラベルは、**この PC で P-touch Editor の『バーコード印字.lbx』を開いて、人が選んで刷って**います。

これを、**iPad の いろは在庫化作業アプリで「🏷 箱ラベル」を押したら、この PC の QL-800 から勝手に出てくる**ようにします。
出てくるラベルは今と同じレイアウトです (商品名・数量 (1 箱に何個)・期限・バーコード)。

```
iPad の詳細画面で「🏷 箱ラベル」を押す (1 箱に何個・期限・枚数を確かめて「発行する」)
   ↓ ポータル (Render) が「この商品を何枚」という注文書を箱に入れる
   ↓ この PC の中に住まわせた「印刷係」が 4秒ごとに箱をのぞく
   ↓ 注文書があれば、テンプレに商品名・数量・期限・バーコードを入れて QL-800 へ
🖨 ラベルが出る → iPad に「✅ 印刷しました」
```

「印刷係」は、倉庫PCで動いている値札シールの印刷係と**同じ作り**です (テンプレと出力先が違うだけ)。

**印刷係がテンプレを動かすには、ブラザーの「b-PAC」という無料の部品が要ります。** それを入れるのが ① です。

## ① b-PAC を入れる (10分)

「b-PAC」= ブラザーが無料で配っている部品。P-touch Editor のテンプレ (.lbx) をプログラムから開いて刷るためのもの。

1. ブラザーのページを開く
   ```
   https://support.brother.co.jp/j/s/es/dev/ja/bpac/download/index.html
   ```
2. 「ユーザー登録が必要」と出るので、**メールアドレスで無料登録**してログイン (会社のメアドで OK)
3. 「b-PAC 3.4」の **64ビット版** をダウンロード (「一式」と「本体のみ」が選べる場合は **「本体のみ」(Client Component)** で十分)
4. ダウンロードしたファイルをダブルクリック →「このアプリがデバイスに変更を加えることを許可しますか?」→ **はい** → あとは「次へ」「同意する」「インストール」
5. できたか確かめる → そのまま ② へ (② のテストの最初で「b-PAC OK」と出れば入っています)

## ② テストする (5分) — `3_テストする.bat` をダブルクリック

```
G:\共有ドライブ\入荷バーコード発行\箱ラベル印刷係\3_テストする.bat
```

> 💡 これは**右クリック不要**。ふつうにダブルクリックで OK。紙は「y」と答えるまで出ません。

### 🚨 先に 1回だけ: QL-800 に「箱ラベルの大きさ」を登録する (2分)

b-PAC はテンプレに書いてある大きさ (62mm × 67.2mm) を**無視**して、プリンターの用紙一覧にある大きさで刷ります (倉庫PCの QL-700 で実測した癖。QL-800 も同じドライバーの仲間)。
QL-800 の一覧には 62 × 67.2 が無いので、何もせずに刷ると **29mm や 90mm の長さ**になってしまいます。
そこで、QL-800 のドライバーに「箱ラベルの大きさ」を 1回だけ登録します。

1. Windows の **[設定] → [Bluetooth とデバイス] → [プリンターとスキャナー] → [Brother QL-800] → [印刷設定]**
   (見つからなければ: コントロールパネル → デバイスとプリンター → Brother QL-800 を右クリック → 印刷設定)
2. **[拡張設定]** タブ → 一番下の **「長尺テープフォーマット(N)」の [設定...]** ボタン → 登録画面が開く
3. **[新規]** → 次のとおり入れて [OK]

   | 項目 | 入れる値 |
   |---|---|
   | 名前 | `箱ラベル 62x67` (半角スペース入り。1文字も違わないように) |
   | 幅 | **62mm** (長尺) |
   | 長さ | **67.2** mm |
   | 左右余白 | そのまま |

4. **[終了]** → 印刷設定の画面も **[OK]** で閉じる (「管理者の許可」を聞かれたら **[はい]**)

> 💡 登録し忘れても大丈夫です。テストはプレビューの大きさが違うことに気づいて、手順を表示して**刷らずに止まります**。

> ⚠ **[2/5] で「△ プリンターの用紙一覧に出てきませんでした」と出ても、そのまま進んでください。** QL-800 では、登録した長尺テープフォーマットを**プログラムから使えない**ことが分かりました (2026-09-06 いろはPC 実測)。そのため、上の「箱ラベル 62x67」の登録は**実は必須ではありません** (してあっても害はありません)。

> ⚠ **プログラムはドライバー標準の用紙「62mm」(長尺) で絵を描き、印刷するときに 67.2mm の紙に出します。** 長尺ロールは長さが決まっていないので、b-PAC は中身に合わせた長さで絵を描きます。**そのため [5/5] のプレビューの長さは 67.2mm とは違う数字になります。これで正常です。** 長ければ切り落とし、短ければうしろが白紙になるだけで、実際に出てくるラベルは 67mm です。

> ⭐見てほしいのは長さではなく、**商品名・バーコード・数量・期限がそろっているか**です。

> 🚨 大事なのは**プリンターに 62mm 幅の連続 (長尺) ロールが入っていること**です。ダイカット (1枚ずつ切れている) のロールだとテスト が止まります。

### 黒い画面が開いて、順番に進みます

```
=== 保管箱ラベルの印刷テスト (いろはPC  2026-09-06 15:00) ===

[1/5] b-PAC ......... OK (64ビット)          ← ① がうまくいっていればここが OK
[2/5] 用紙 ........... △ 「箱ラベル 62x67」はプリンターの用紙一覧に出てきませんでした… ← QL-800 ではこれが普通。そのまま進む
[3/5] テンプレ ....... OK (JAN用 / FNSKU用 の2本。中身は同じ『バーコード印字.lbx』のコピー)
[4/5] 試し刷りの商品 ... 本物の商品データ (バーコードマスタ.csv) から 1 行使います: 01520-01
      サロンジェ すみっコぐらし 子供エプロン …
      バーコード : 4975953878050 (JAN)   数量 (1箱に何個) : 24   期限 :
[5/5] プレビュー ..... OK  用紙「62mm」 62mm × (長さは自動)  画像を開きます → …\hakolabel_preview.bmp
```

### ここで画像が開きます → **手で刷っている箱ラベルと見比べる**

**長さは気にしないでください** (印刷時に 67.2mm に合わせます)。中身がそろっているかだけ見てください。

- 上の商品名の場所と大きさ
- 真ん中のバーコードと、その下の文字
- 下の「数量」の数字 (テストでは 24) と、その右の期限 (期限管理ありの商品だと「期限あり」と入ります)

**同じ見た目なら `y`** を押して Enter。1枚出ます。
違うところがあれば **`n`** で止めて、何が違うか Claude に伝えてください (紙は使いません)。

### 1枚出たら

- 出たラベルを手で刷ったものと並べて見る
- **ハンディでバーコードを読んで、商品が合っているか**見る

画面には「印刷キューに現れたジョブ」「○ 文書名に目印が載っています」のような行が出ます。**○ が2つ**なら理想です。**△ が出ても紙が出ていれば大丈夫** — その旨を Claude に伝えてください。

### 「もう1回、3枚まとめて刷ってみますか?」

`y` を押すと **3枚**出ます。**1枚ずつ切れて出るか**を見てください (くっついて出たら Claude に伝える)。

### 終わったら

同じフォルダに **`RESULT_test.txt`** ができています。**これを Claude に見せてください。**

## ③ 印刷係を住まわせる (5分)

1. パソコン (中原さんの PC でも、この PC でも) で `https://bfaith-portal.onrender.com/apps/iroha-work/admin` を開き、
   「🏷 保管箱ラベル (いろはPC の Brother QL-800)」の節で 端末名 `いろはPC` / プリンター名 `Brother QL-800` (「プリンターとスキャナー」の表記どおり) →
   「🏷 印刷係を登録してトークンを発行」→ **合言葉 (トークン) が1回だけ表示**される → コピー
2. この PC で `1_設置する.bat` を **右クリック →「管理者として実行」** → 合言葉を貼り付けて Enter
3. `----- done -----` と出れば、印刷係が住みました (再起動しても・誰もログインしていなくても動く。PC が寝ないようにも設定される)。
   実行に必要なものは `C:\tools\iroha-label-agent\` にコピーされます (G ドライブは常駐の印刷係からは見えないため)
4. iPad で商品を開き「🖨 箱ラベルを印字する」→ QL-800 から出る (ボードのカードからも押せます)

> 💡 端数の箱があるときは、最後の 1 枚だけ数量を変えて刷ります。例: 必要保管箱 6 箱 (70×5＋10) → 70 個のラベル 5 枚 ＋ 10 個のラベル 1 枚。iPad のダイアログに「合計 6 枚」と出るので、そこを見てから発行してください

倉庫PCの値札印刷と**まったく同じ手順**です。

## うまくいかないとき

| こんなとき | たぶん | どうする |
|---|---|---|
| `[1/5] b-PAC ... まだ入っていません` | ① が終わっていない / 32ビット版を入れた | ① をやり直す (64ビット版)。32ビット版でも動くよう作ってありますが、その場合は Claude に一言 |
| `[2/5] 用紙 ... △ 用紙一覧に出てきませんでした` | **QL-800 の癖。登録できていてもこう出ます** | そのまま進んでください (止まりません) |
| `[5/5] プレビュー ... 失敗` で用紙の手順が出た | 用紙が本当に未登録 / 名前が 1文字違う | 画面に出る手順どおりに登録 (名前は `箱ラベル 62x67`) → もう一度 bat |
| `[5/5] プレビュー ... 大きさが違います` | 62mm 幅の連続 (長尺) ロールが入っていない | プリンターのロールを見る。ダイカットではなく 62mm の連続ロール (DK-22205 互換) |
| プレビューの長さが 67.2mm と違う | **正常です**。長尺ロールは長さ自動で、印刷時に 67.2mm に合わせます | そのまま進んでください |
| `[2/5] プリンター ... 応答しません` / `この PC にありません` | 電源が入っていない / USB が抜けている / プリンター名が違う | プリンターを見る。名前は「プリンターとスキャナー」の表記どおりに (`config.example.json` の printerName) |
| プレビューの見た目が違う | b-PAC の描き方が Editor と少し違う | `n` で止めて、どこが違うか Claude に |
| 紙が出ない | テープが入っていない / USB / 電源 | プリンターを見る。それでも出なければ `RESULT_test.txt` を Claude に |
| `△ 目印が見えませんでした` だけど紙は出た | 印刷が速すぎて見えなかった | そのまま Claude に伝える |
| 3枚がくっついて出た | カットの設定が違う | Claude に伝える |
| 設置のあと iPad に「🙋 印刷係が応答しません」 | PC が寝ている / 印刷係が止まっている | `2_状態を見る.bat` → `RESULT_status.txt` を Claude に |

わからなくなったら、`RESULT_test.txt` / `RESULT_status.txt` を Claude に見せれば、どこで止まったか分かります。

## 🚨 覚えておいてほしい、たった1つのこと (本番になってから)

### iPad に「❓ 結果不明 (実物を確認)」と出たら、**もう1回押さない**

まず **プリンターの実物を見てください。** ラベルが出ていたら、それを使えば大丈夫です。

印刷の途中で PC が落ちたときなど、「紙が出たかどうか分からない」ことがあります。このとき勝手に刷り直すと、**同じ商品のラベルが2枚**になり、別の箱に貼られると棚が狂います。

1枚出ないのは、もう1回押せば直ります。**2枚出て別の箱に貼られると気づけません。** だから「分からないときは、人が実物を見る」ようにしています。
出ていなかったときだけ、iPad で「実物を確認した (ラベルは出ていない)」にチェックして、もう一度発行してください。

> 「⚠ 印刷できませんでした」と出たときは**確実に出ていない**ので、もう1回押して大丈夫です。
