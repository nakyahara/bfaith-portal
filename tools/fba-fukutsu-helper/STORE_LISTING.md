このファイルは提出時にコピペするための下書き。**登録・支払い・提出は中原さんのGoogleアカウントで行う。**

## 前提

- デベロッパー登録料 **$5 は1回きり**。`ne-select-set-helper` で既に登録済みなら**追加費用なし**
- 公開範囲は **「非公開（Private）」**。b-faith.biz の Google Workspace アカウントで
  ログインしている人だけがインストールできる
- ⭐ **この拡張は権限をひとつも要求しない**（`permissions` も `host_permissions` も空）。
  外部との通信もしない。審査で聞かれる項目はほぼ「なし」で答えられる

## 手順

1. https://chrome.google.com/webstore/devconsole に **b-faith.biz のアカウント**でログイン
2. 「新しいアイテム」→ **zipをアップロード**
   （ポータルの「拡張機能をダウンロード (zip)」で落としたものをそのまま使える。
   `make-icons.mjs` と `STORE_LISTING.md` は自動で除外される）
3. 下の各項目を貼り付ける
4. 「公開設定」→ **非公開**（組織内のみ）
5. 審査に提出

### 概要（132文字以内）
```
Amazon Seller Central の納品プラン画面から、福山通運の送り状CSVを作ります。宛先コードと箱数の手入力が不要になります。B-Faith社内専用。
```

### 詳細な説明
```
B-Faith 社内専用のツールです。社外の方はご利用いただけません。

■ 何をするか
Amazon の FBA 倉庫へ納品するとき、輸送箱ごとに福山通運の送り状が必要です。
これまでは Seller Central の画面を見ながら、宛先コードと箱数を別のスプレッドシートに
手で書き写して送り状データを作っていました。
この拡張機能は、Seller Central の画面に出ている情報をそのまま読み取って、
福山通運の送り状発行ソフトに取り込めるCSVを作ります。

■ 使い方
1. Seller Central で納品手続きを進め、「印刷された輸送箱ラベル」の画面まで進む
2. 画面右下に出る「福通伝票CSV」ボタンを押す
3. 納品番号・宛先・箱数の一覧が表示されるので確認する
4. 「この内容でCSVを作る」を押すとCSVが保存される
5. 保存したCSVを送り状発行ソフトに取り込む

■ 通信しません
必要な情報はすべて画面に表示されているため、外部のサーバーとは一切通信しません。
拡張機能の権限もひとつも要求しません。

■ 安全のための作り
・ボタンを押したときだけCSVを作ります（自動では作りません）
・画面から読み取れない項目があるときは、CSVを作らずに理由を表示します
・ダウンロードの前に必ず内容を確認できます

■ 取得する情報
この画面に表示されている納品番号・配送先の倉庫コード・住所・箱数・出荷日のみを読み取ります。
個人のお客様の氏名・住所・電話番号・メールアドレスなどは一切扱いません。
読み取った内容は端末内でCSVに変換されるだけで、どこにも送信されません。
```

## スクリーンショット（1枚以上必要・1280x800 か 640x400）

**用意済み**: `store/screenshot-1280x800.jpg` をそのままアップロードする。

⭐実画面のキャプチャは使わない。Seller Central には注文者情報が写り込む恐れがあるため、
説明用のHTMLを描画して撮っている (select-set と同じ方針)。作り直すときは:

```
node tools/fba-fukutsu-helper/store/make-screenshot.mjs
```

図や文言を変えたいときは `store/screenshot.html` を直して再実行する。
`store/` は配布zipには含まれない。

## 公開後にやること

- Google Workspace の管理コンソール →「Chrome」→「アプリと拡張機能」で
  **対象PCへ自動インストール**を設定できる。会社PCと伝票出しPCに配るならこれが最短
- 更新するときは `manifest.json` の `version` を上げて zip を再アップロードする

node tools/fba-fukutsu-helper/make-icons.mjs
