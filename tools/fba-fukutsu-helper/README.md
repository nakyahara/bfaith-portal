# FBA納品 福通伝票CSV (Chrome拡張・社内用)

Amazon Seller Central の納品プラン画面から、福山通運 iS-2 に取り込む
**送り状CSV (26列)** をその場で作る。

## これで何が変わるか

```
旧: Seller Centralを見ながらスプレッドシートに宛先コードと箱数を手入力 → GASでCSV生成
新: 納品プラン画面の「📦 福通伝票CSV」を押す → CSVが落ちる
```

⭐ CSVの **U列「お客様管理番号」に Amazonの納品番号** が入る。
これにより毎晩22時の追跡番号の自動投入が、FCコードや箱数からの推測なしに
一意で決まる (同じFC宛の納品が同時に複数あっても取り違えない)。

## 使い方

1. Seller Central で納品プランを開く (URLに `?wf=` が付いている画面)
2. 右下の **📦 福通伝票CSV** を押す
3. 納品番号・宛先・箱数を確認して **[この内容でCSVを作る]**
4. 落ちてきたCSVを iS-2 の「CSVエントリー」から取り込む → ラベルを印刷

**押したときだけCSVを作る。** 伝票発行は運賃が発生する不可逆な操作なので、
自動生成にせず「どの納品をいま出すか」を人が決める形にしてある。

## インストール

1. Chrome の `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選ぶ
4. 拡張の「詳細」→「拡張機能のオプション」で **APIトークン** を入れる
   (ポータルの `.env` の `FBA_TRACKING_EXT_TOKEN` と同じ値)
5. 「接続テスト」で確認

## 仕組み

- APIトークンは Service Worker だけが持つ。ページ側の world には出さない
- SP-API の資格情報は **ポータルにしかない**。拡張は配布物なので鍵を持たせない
- 呼ぶのは読み取りAPIだけ。Amazonへの書き込みも福山通運のシステムへのアクセスもしない
  (作ったCSVは人が iS-2 から取り込む = 従来と同じ公式ルート)

| | |
|---|---|
| 呼び先 | `GET /apps/fba-replenishment/ext-api/plan` (下見) / `…/plan-csv` (CSV) |
| 認証 | `x-api-key` (env `FBA_TRACKING_EXT_TOKEN`・未設定ならポータルが503で拒否) |
| サーバ側 | `apps/fba-replenishment/tracking-ext-router.js` |
