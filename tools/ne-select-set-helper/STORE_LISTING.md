## ストアの掲載情報

### アイテム名

### 概要（132文字以内）
```
ネクストエンジンの受注伝票で「選べる〇種セット」を、お客様が選んだ実際の商品コードの明細行に展開します。B-Faith社内専用。
```

### 詳細な説明
```
B-Faith 社内専用のツールです。社外の方はご利用いただけません。

■ 何をするか
モールで販売している「選べる〇種セット」は、組み合わせが多すぎて商品マスタに登録できないため、
仮の商品コードで受注が入り、そのままでは在庫の引当ができません。
お客様が選んだ商品は受注明細の「商品オプション」欄に記録されているので、
この拡張機能がそれを読み取り、実際の商品コードの明細行に展開します。

■ 使い方
1. ネクストエンジンの受注伝票を開く
2. 対象の明細行があれば、明細一覧の上に案内パネルが表示される
3. 「展開する」を押すと、追加される明細行の内容が表示される
4. 内容を確認して「この内容でNEに入れる」を押す
5. 保存は担当者が行う

■ 注意
・自社の社内サーバーへの接続設定（URLとAPIキー）が必要です
・展開できない選択肢が1つでもある場合は、何も入力せずに停止します

■ 取得する情報
このツールは商品コードと数量のみを扱います。
お客様の氏名・住所・電話番号・メールアドレスなどの個人情報は一切読み取りません。
```

## プライバシー（審査で聞かれる項目）

### 単一用途の説明
```
ネクストエンジンの受注伝票画面で、セット商品の選択内容を実際の商品コードの明細行に変換して入力する。
```

### 権限の理由

| 権限 | 理由 |
|---|---|
| `storage` | 接続先URLとAPIキーを保存するため。ユーザーが設定画面で入力した値のみを保存する |
| `https://bfaith-portal.onrender.com/*` | 自社の業務ポータル。商品コードの変換表を取得するために接続する |
| `https://wh.bfaith-wh.uk/*` | 自社の社内サーバー (予備の接続先) |
| `http://localhost/*` | 開発時の動作確認用 |
| `main.next-engine.com/Userjyuchu/*` のコンテンツスクリプト | 受注伝票画面でのみ動作させるため。対象を受注伝票画面に限定している |

### リモートコードの使用

使用しない（すべてのコードはパッケージに含まれている）
```

### データ収集の申告

このツールが送信するのは「セットの商品コード」と「商品オプションの文字列（商品名や香りの選択内容）」
だけであり、個人を特定できる情報は含まない。送信先は自社サーバーのみ。
```

## 公開後にやること

- Google Workspace の管理コンソール →「Chrome」→「アプリと拡張機能」で
  **対象PCへ自動インストール**を設定できる（`ExtensionInstallForcelist` 相当）。
  会社PCに一斉配布したい場合はこちらが最短
- 更新するときは `manifest.json` の `version` を上げて zip を再アップロードする。
  ストア経由なら各PCへ自動で配られる
